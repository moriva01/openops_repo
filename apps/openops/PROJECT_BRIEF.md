# OpenOps Evidence

## Product brief

An independent open-source operations platform for small IT teams. It collects server and application telemetry, detects sustained problems, preserves evidence and verifies recovery. Its implemented investigation layer uses AI to compare explanations and recommend evidence-linked next checks.

## Demonstration application

TeleMediation Convergent processes synthetic voice, SMS and data usage through input portals, mediation and output portals. Blocking VOICE output creates a measurable backlog while other channels continue. Restoring output drains the queue and establishes recovery.

Host metrics are real. Telecom usage is synthetic. This is a laboratory application, not a live carrier network or billing system.

## Current sponsor contribution

Zetaris exposes a read-only view of the telemetry database and returns the observations used by the monitor evaluator. Charts use application PostgreSQL directly; these paths are documented separately.

## Implemented AI contribution

A minimal Meterless World Model adaptation maintains grounded entities, observations and declared relationships. Nightshift supplies real NVIDIA generation through an injected adapter. Bounded planner, investigator and evaluator calls produce cited hypotheses, alternatives and missing-evidence checks. No repair is executed.

## Investigation design

Validate the host/time window, retrieve bounded evidence, identify gaps, make a limited number of read-only tool calls, compare hypotheses, validate citations and publish evidence, uncertainty and next checks. Preserve a trace without credentials. A plausible explanation must not be presented as proven causation.

## Delivery principles

Use original source and synthetic fixtures. Declare actual external dependencies and accurately report work completed during the event. Keep provider runtimes under their own terms. Ship runnable setup instructions, tests, a 1–4 minute video and required slides. Distinguish implemented features from planned features.
